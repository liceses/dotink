## 它的参数 —— **"表现力"就是从这几个数来的**

| 项 | 值 | 说明 |
|---|---|---|
| **点距** | **8 px**（08 拍 **6 px**） | 1280×720 舞台上 = **160×90 = 14,400 格** |
| **点半径** | **0 .. 3.2 px** 连续调幅 | `maxFrac = 3.2/8 = 0.40`（在标准上限 0.5 之内） |
| 渲染 | 纯 JS 算 RGBA + `putImageData` | **真圆盘**；无 shader / 无 WebGL / 无 three.js；**每帧零随机** |
| 每拍 | 一屏**一个母题**，母题**占满画面** | 向日葵盘直径 ≈ 画幅高；Kuramoto 是大相位环；分叉树横贯全幅 |
| 构图 | 每屏一句**大字标题** + 公式 + 来源 | 不是小标签 |
| 手调 | 逐现象 | 01 用 **3200 颗沙**沿 −∇\|φ\| 迁移（兑现字幕「沙自己走到该在的地方」）；06 被用户打回"仪表盘"版后重做成相位环；08 用 6 px 因为条纹间距要跟网点可分辨 |

**实测（本次量的 1:1 静帧）**：墨量 2.95 %（07 分叉）– 15.21 %（04 Gray-Scott）；
网格周期在静帧里 9–12 px —— 那是**设备像素**（×1.5），除以 1.5 就是 CSS 的 6–8 px ✓ 与上表一致。

## 怎么重建（在 lab 里）

```powershell
cd D:\developing\make-videos-kit\lab
node modules/wireframe/build.mjs
node modules/wireframe/render.mjs work/lab-field4/film/lab-field4.html --keep-frames
# 标定脚本（参数怎么来的都留着）：work/lab-field4/tools/tune-sand.mjs
# 查某块画布的墨落在哪一带：node work/lab-field4/tools/probe-canvas.mjs --id cv0 --at <秒>
#   ⚠ --at 的单位是**秒**，不是帧号（里程碑里记着"今天栽过四次"）
```

## 判定纪律（摘自里程碑，和本包标准同源）

- 细节（点 / 环、点的大小、沙粒是否成线）**必须看 1:1** —— 缩略图既藏缺陷也造假缺陷；
- "看得见 / 看不见"一律**先量**（探针），不靠感觉；
- **冻结件不悄悄改**：01 的画面换了就另开一份里程碑，旧的留在 git 历史与 `D:\backups\`。

## 为什么放进 dotink 包

它是本标准 §4（M2 面场 / M3 结构线刻）的**参考配方**，也是"表现力"的标尺：
**同一个现象，点距细一倍、母题占满、每屏一句大字，画面就是另一个量级。**

本包自己的自检片（`../1010-dotink-demo-1080p.mp4`）用的是同一批公式，但点距 16 px、母题偏小、
还压着标签卡 —— 两相对照，差在哪一目了然（见包 README「同一批公式，差在哪」）。
