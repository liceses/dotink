Dot Ink · Scale · 4px

尺度

颜色有两层（画布 / 界面），尺寸只有一层：theme/scale.json → scale.css。这一页的每一行样张都是从那份数据现算出来的，不是手抄的样张 —— 改了数据，这一页跟着变；改了这一页不会变，因为字号不在这里写。

为什么界面也要有阶：画布只有 0/1 两色、网点只有面积差别，它没有中间调。界面如果留着 9.5px / 13.5px 这种半像素档，就等于在承诺一种画布给不了的分辨率。

字阶：八档，行高全在 4px 网格上

字号不要求是 4 的倍数（10 / 14 / 26 是字体的光学尺寸），但行高必须是 —— 版面的节奏在行高，不在字号。下面每行右边的灰格就是 4px 基线，行距没对齐会立刻看出来。

间距：十级，最小 4px

每一条的真实宽度就是那个令牌的值（不是示意图）。间距阶之外没有别的值 —— check/scale.mjs 会扫描所有页面的 padding / margin / gap。

三个基础量：线宽、时长、中文字号

只有两种线。1px 纸缝（分隔，不表态）与 2px 墨框（表态、围住一块判据）。没有 3px，没有渐变描边，没有圆角。

--bw-hair1px
--bw-frame2px

只有两档时长。140ms 用于即时反馈（hover、按下），160ms 用于位置变化。渲染路径上的动画不受这条约束 —— STANDARD §9 禁的是逐帧确定性，不是 DOM 过渡。

--dur-fast140ms
hover 它
中文最小12px
拉丁 10px 可以（DOT INK · 2026）中文 12px 起（点墨）

10px 那一档只给拉丁与数字：这一页自己在 9.5px 的中文上试过一次，笔画已经发虚 —— 那不是"精致"，是浏览器在替你舍入。

五条格律

R1 · 量化，不插值

八档就是八档。字号与行高之间不写"差不多"的中间值；要更大就换档。

反例 font-size:13.5px

正例 font-size:var(--t-body)

R2 · 4px 格律

所有间距、行高、控件高度都是 4 的倍数。4 能整除画布点距 8 / 12 / 24，DPR 1 / 1.5 / 2 下都是整数设备像素。

反例 padding:11px 14px

正例 padding:var(--s3) var(--s4)

R3 · 只有两种线

1px 纸缝、2px 墨框。零圆角、零外投影 —— 这两条全站已经在遵守，门禁把它们钉住。

反例 border-radius:6px

正例 border-radius:0

R4 · 状态用墨，不用色

在动 = 实心方块；停住 = 空心；到端点 = 圆点；判据不过 = --alert。强调色只做装饰（它对纸只有 3.01:1）。

反例 「过了」用绿色

正例 过了 = 墨，不过 = --alert

R5 · 数字交给等宽

所有读数用等宽 + tabular-nums，右对齐、同宽。点墨的读数牌是判据的一部分 —— 覆盖率、点距、tac 抖一下，数字就不信人。

反例 覆盖率 11.2% / 8.7%

正例 覆盖率 11.20% / 8.70%

组件目录

这一族是全站共用的 DOM 件。名字带 ink- 前缀的一律来自 ink.css，页面里不再重抄。

怎么改一档

改数据、重生成、跑门禁 —— 三步。手改生成件会被 --check 当场抓住。

# 1. 改唯一真源 # theme/scale.json —— 加一档字阶 / 调一级间距 / 改基础单位 # 2. 重新生成 scale.css 与 scale.js node tools/build-scale.mjs # 3. 跑门禁（裸字号、离阶间距、字体单源、形制、引入顺序、行高种数） node --test check/scale.mjs npm run check

要加一个组件：先在 ink.css 里用令牌写一条（不许出现数字与颜色），再在这里挂一个真实实例。组件目录里如果出现"只有图没有实例"的条目，说明它已经和代码脱节了。
