六套纸墨

标准只认两个颜色：墨 [12,13,14]、纸 [242,243,242]。 但那是画布的规矩，不是站点的。这一页把两层拆开：界面令牌随便换，画布令牌要换就得记账。

点右上角的方块换纸色 —— 整个站点（含这一页的表格）会一起换，画布上的点也跟着换墨色。 选择存在本地，刷新不丢；选「跟随系统」就交回给 prefers-color-scheme。

令牌三层

第一层进 canvas，第二层只进 DOM，第三层是给旧页面用的别名。换主题时三层的联动是自动的。

① 画布层只有这两个颜色会进 DotInk.create({ink,paper})。标准套里它们逐位等于 STANDARD §1。--c-ink · --c-paper
② 界面层正文、辅助字、描线、面板、强调、警示、焦点环。这一层可以抗锯齿，不受「只有墨与纸」约束。--fg · --page · --rule …
③ 兼容别名--ink 指向 --fg，--paper 指向 --page。旧页面不改一个字也能跟着换。--ink → --fg

六套配色

每张卡下方是「网点梯尺」：同一个场，八个墨量档，点面积按 r = rMax·√w 走。 这就是为什么要成套换 —— 只换界面不改画布，梯度会散架。

对比度门禁

下面每一个数都是 theme.js 里现算的（DotInkTheme.gates()）， 与 check/theme.mjs 判的是同一份代码。门限：正文类 ≥ 4.5，装饰类 ≥ 3.0。

加一套

配色是数据，不是样式产物。改完必须重跑生成器，否则 npm run check 会红。

# 1) 在 theme/palettes.json 的 palettes 里加一条（slug 用 kebab-case）
# 2) 重新生成 theme.css / theme.js —— 对比度不过会直接 exit 1
node tools/build-theme.mjs
# 3) 验收：结构、门禁、零漂移、裸色禁令
node --test check/theme.mjs
